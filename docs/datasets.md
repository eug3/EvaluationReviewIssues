# 数据集清单

记录本项目可用的 RAGFlow 数据集，供后续检索复用。

## 服务端

- **MCP 地址**：`http://10.1.1.230:9382/mcp`（HTTP Streamable，无鉴权）
- **服务标识**：`ragflow-mcp-server` v1.19.0
- **协议版本**：`2025-06-18`
- **唯一工具**：`ragflow_retrieval`

### 工具参数

| 参数 | 说明 |
| --- | --- |
| `question` | 检索问题（必填） |
| `dataset_ids[]` | 限定数据集；**不传则全库检索** |
| `document_ids[]` | 限定文档 |
| `page_size` | 每页条数（默认 10） |
| `similarity_threshold` | 相似度阈值（默认 0.2） |
| `vector_similarity_weight` | 向量权重（默认 0.3） |
| `keyword` | 是否启用关键词检索（默认 false） |
| `page` | 页码 |

### 返回字段

| 字段 | 说明 |
| --- | --- |
| `content` | 命中的文本片段 |
| `document_name` | 来源文档名 |
| `similarity` | 相似度得分 |
| `positions` | `[页码, ...]` 坐标信息，可用于定位 PDF 原文位置 |
| `dataset_name` / `dataset_id` | 数据集信息 |
| `document_metadata` | 文档元数据（大小、chunk 数、创建时间等） |

### 检索示例

限定该数据集检索：

```
ragflow_retrieval(
  question="无形资产 收益法 折现率",
  dataset_ids=["d6edbed44e7a11f18ee0afe6a78982c3"],
  page_size=20,
  keyword=true
)
```

### 使用建议

- 结果集可能较大（单次 20 条即约 65KB），建议将结果落盘后用脚本统计 `document_name` 分布、按 `similarity` 排序，再精读目标片段，比直接全量读取更省 token。
- 需要提高精确度时，调高 `similarity_threshold`；需要扩大召回时，降低该值或开启 `keyword`。
