# 数据集清单

记录本项目可用的 RAGFlow 数据集，供追问取证与准则依据检索复用。

## 服务端

- **MCP 地址**：`http://10.1.1.230:9382/mcp`（HTTP Streamable，无鉴权）
- **服务标识**：`ragflow-mcp-server` v1.19.0
- **协议版本**：`2025-06-18`
- **唯一工具**：`ragflow_retrieval`

### 工具参数

| 参数 | 说明 |
| --- | --- |
| `question` | 检索问题（必填） |
| `dataset_ids[]` | 限定数据集；**不传则全库检索** |
| `document_ids[]` | 限定文档；**把召回锁定到某一部准则或某一份底稿的关键手段** |
| `page_size` | 每页条数（默认 10，建议 ≤50） |
| `similarity_threshold` | 相似度阈值（默认 0.2；条款精确检索可降到 0.05–0.1） |
| `vector_similarity_weight` | 向量权重（默认 0.3） |
| `keyword` | 是否启用关键词检索（默认 false；**查条款编号/文号时置 true**） |
| `page` | 页码 |

### 返回字段

| 字段 | 说明 |
| --- | --- |
| `content` | 命中的文本片段 |
| `document_name` / `document_id` | 来源文档 |
| `similarity` | 相似度得分 |
| `positions` | `[page, x1, y1, x2, y2]` 坐标，可定位 PDF 原文位置 |
| `dataset_name` / `dataset_id` | 数据集信息 |
| `document_metadata` | 文档元数据（大小、chunk 数、创建时间等） |

## 三、检索建议（playbook）

1. **查准则条款**：`dataset_ids=["d6edbed..."]` + `document_ids=[某部准则]` + `keyword=true` + `similarity_threshold=0.05~0.1`，可直接命中"第X条"原文。
2. **给追问补依据（S2）**：把追问文本作为 `question`，限定 `document_ids` 到对应准则，取回条款作为 `ground`。
3. **底稿取证（S3）**：`document_ids` 限定到案例的说明/明细表，**绝不放报告文档**；`keyword=true` 有助于命中数字和科目名。
4. **报告命题抽取（S1）**：用章节探针问题（见 `cases/_template/case.yaml` 的 `report_probe_questions`）召回报告各章节 chunk。
5. **结果集可能较大**：单次 20 条约 65KB，建议先落盘再用脚本统计 `document_name` 分布、按 `similarity` 排序，再精读目标片段。
6. **定位原文**：用 `positions` 的页码坐标回到 PDF 核对。

### 检索示例

```
# 核实国资指南的评估说明条款
ragflow_retrieval(
  question="评估说明 使用范围声明 企业关于进行资产评估有关事项的说明 资产评估说明 应当包括",
  dataset_ids=["d6edbed44e7a11f18ee0afe6a78982c3"],
  document_ids=["bb8d1e804e7c11f18ee0afe6a78982c3"],
  page_size=8, keyword=true, similarity_threshold=0.1
)
```

## 五、维护约定
