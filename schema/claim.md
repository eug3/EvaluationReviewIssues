# 报告命题类型（claim types）

> 报告中「可判定陈述」的分类，共 13 类；机器可读版 schema/claim.yaml。

## 总览

| id | 名称 | 对应追问组 |
| --- | --- | --- |
| object_scope | 评估对象与范围 | object_scope |
| value_type | 价值类型 | value_type |
| base_date | 评估基准日 | base_date |
| purpose | 评估目的与委托人 | purpose |
| method | 评估方法与适用性 | method |
| parameter | 评估参数 | parameter |
| calculation | 计算过程与公式 | calculation |
| conclusion | 评估结论与金额 | conclusion |
| change_analysis | 评估值与账面值变动分析 | change_analysis |
| assumption | 评估假设与前提 | assumption |
| limitation | 限制条件与特别事项 | limitation |
| disclosure | 披露一致性与核对字段 | disclosure |
| legal_basis | 评估依据与权属 | legal_basis |
---

## object_scope 评估对象与范围

评估对象、评估范围、资产类型与数量、账面无记录/表外资产

**检测提示**：
- 评估对象
- 评估范围
- 纳入评估范围
- 表外资产
- 账面未记录

**示例**：
- 评估对象为南京七伙科技合伙企业（有限合伙）股东全部权益
- 评估范围包括全部资产及负债

## value_type 价值类型

报告采用的价值类型及其定义（市场价值/投资价值/在用价值/清算价值等）

**检测提示**：
- 价值类型
- 市场价值
- 投资价值
- 在用价值
- 清算价值
- 残余价值

**示例**：
- 本次评估的价值类型为市场价值

## base_date 评估基准日

评估基准日的日期、选取理由及期后事项处理

**检测提示**：
- 评估基准日
- 基准日

**取值字段**：
- date

**示例**：
- 评估基准日为 2021 年 6 月 30 日

## purpose 评估目的与委托人

评估目的、委托人、报告使用人及经济行为

**检测提示**：
- 评估目的
- 委托人
- 报告使用人
- 经济行为
- 拟受让

**示例**：
- 评估目的为南京紫金新兴产业创业投资基金有限公司拟受让股权

## method 评估方法与适用性

采用的评估方法、方法选择理由、未采用其他方法的说明

**检测提示**：
- 评估方法
- 收益法
- 市场法
- 成本法
- 资产基础法
- 采用
- 不适用

**示例**：
- 本次评估采用收益法
- 资产基础法不适用

## parameter 评估参数

关键参数取值（折现率、增长率、资本化率、成新率等）及取值依据

**检测提示**：
- 折现率
- 增长率
- 资本化率
- 成新率
- WACC
- 加权平均资本成本
- 取

**取值字段**：
- value
- unit

**示例**：
- 折现率取 10.5%
- 长期增长率为 3%

## calculation 计算过程与公式

从参数到结论的计算步骤、公式、口径与勾稽关系

**检测提示**：
- 计算公式
- 计算过程
- =∑
- 折现
- 现值
- 口径

**取值字段**：
- formula
- value
- unit

**示例**：
- 评估值 = 预测期现金流现值 + 永续期现值

## conclusion 评估结论与金额

评估结论、评估值（含大小写）、增减值、增值率

**检测提示**：
- 评估结论
- 评估值
- 评估结果为
- 增减值
- 增值率
- 大写

**取值字段**：
- value
- unit
- currency

**示例**：
- 股东全部权益评估值为 12,345.67 万元
- 评估增值 2,345.67 万元，增值率 23.45%

## change_analysis 评估值与账面值变动分析

评估值与账面值的比较、变动原因及合理性说明

**检测提示**：
- 账面价值
- 评估价值
- 变动原因
- 增值原因
- 比较变动

**取值字段**：
- value
- unit

**示例**：
- 评估增值主要来源于无形资产评估增值

## assumption 评估假设与前提

一般假设、特别假设、预测前提、市场条件假设

**检测提示**：
- 评估假设
- 假设
- 前提
- 持续经营
- 公开市场

**示例**：
- 假设被评估单位持续经营

## limitation 限制条件与特别事项

报告使用限制、特别事项说明、不确定性与风险提示

**检测提示**：
- 特别事项
- 限制条件
- 使用限制
- 风险提示
- 不确定性
- 本报告仅供

**示例**：
- 本报告仅供相关监管机构和部门使用

## disclosure 披露一致性与核对字段

报告摘要、报告结论、说明结论、汇总表之间应当一致的关键字段

**检测提示**：
- 摘要
- 结论
- 汇总表
- 一致

**取值字段**：
- field
- value

**示例**：
- 报告摘要与结论的评估对象、基准日、金额一致

## legal_basis 评估依据与权属

引用的法律法规/准则、权属资料、经济行为文件

**检测提示**：
- 评估依据
- 法律法规
- 权属
- 不动产权证
- 营业执照
- 依据

**示例**：
- 评估依据包括《资产评估基本准则》及不动产权证
