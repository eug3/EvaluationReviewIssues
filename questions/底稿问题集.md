## 1. 送审前置要求（13）

来源：指引 第二部分 电子底稿送审基本要求

- [ ] **Q-SR-001** 工作底稿编制是否符合《资产评估执业准则——资产评估档案》（中评协〔2018〕37号）？
      - 判定要点：合规性底线，逐条对照准则第5-14条
- [ ] **Q-SR-002** 底稿内容是否资料翔实、重点突出、繁简得当、结论明确？
- [ ] **Q-SR-003** 各科目是否严格按《评估步骤及复核表》执行评估程序，复核表是否经项目复核人签字确认后归档？
- [ ] **Q-SR-004** 基本组成是否齐全：资产评估报告、说明、明细表及电子工作底稿（管理类、操作类）？
- [ ] **Q-SR-005** 文件夹层级是否严格按公司规定结构（参照附件2）组织？各层级文件夹名称是否清晰、准确、明确反映内容？
- [ ] **Q-SR-006** 是否仅存放与本次评估直接相关且必要的底稿？无用/不相关底稿是否已剔除？未涉及的资产科目文件夹是否已删除？
- [ ] **Q-SR-007** 送审前是否完成实质性项目复核人审核与一级审核？
      - 判定要点：缺任一级实质性审核，二审直接退回补充
- [ ] **Q-SR-008** 是否使用「评估小助手」编制所有评估科目的核实表并标注索引号？实质性核验底稿文件名是否与核实表索引号一致？
- [ ] **Q-SR-009** 是否所有科目都有核实表？
      - 判定要点：缺核实表直接退回补充
- [ ] **Q-SR-010** 权证类资料是否在现场与原件核对，并在「评估人员签字表」标注“复印件与原件核对一致”、签名（签章）并注明核对日期？不一致是否查明原因并将说明纳入底稿？
- [ ] **Q-SR-011** 引用审计函证作为评估依据时，评估人员是否对原件复核，并在签字表注明“复印件与原件核对一致”并签字、标注日期？
- [ ] **Q-SR-012** 《电子文档盖章资料清单》是否已编制并加盖公章？
- [ ] **Q-SR-013** 需要单独加盖公章扫描的重要资料（申报表、盘点表、权证类、产权声明、资产盘亏说明、抵押担保等权属瑕疵说明等）项目经理是否已识别？

## 9. 评估报告及评估说明低级错误（25）

来源：评估报告及评估说明低级错误定义表（试行稿2012.9.4）

- [ ] **Q-RE-001** 项目名称四要素是否齐全？
      - 判定要点：国有资产/上市公司项目：企业名称+经济行为+评估对象+评估报告；特殊要求应在评估计划中申报并尽早获得审核人员同意
- [ ] **Q-RE-002** 列示目录与后面章节实际目录是否相符（有无目录有内容没有、内容有目录没有、序号重复/跳序/错误）？
- [ ] **Q-RE-003** 是否存在错字、别字、多字、漏字？
- [ ] **Q-RE-004** 项目名称、委托方、产权持有单位、被评估单位名称是否表达一致且与所附营业执照一致？有无「本公司」误用？
- [ ] **Q-RE-005** 页眉、页脚是否正确（含页眉名称与项目名称是否一致）？
- [ ] **Q-RE-006** 目录页码与实际页码是否一致？
- [ ] **Q-RE-007** 有无明显时间差错：现场调查时间早于业务约定书签约时间、评估报告日早于经济行为依据出具时间等？
- [ ] **Q-RE-008** 评估报告、说明、明细表对同一问题是否一致（数值或性质）？各科目账面值/评估结论与明细表、说明是否一致？
- [ ] **Q-RE-009** 企业价值评估项目账面值与所附基准日审计报告或资产负债表是否一致？
      - 判定要点：有审计报告与审定数一致；无审计报告与基准日资产负债表一致
- [ ] **Q-RE-010** 评估基准日与业务约定书、明细表、评估说明中的基准日是否一致？
- [ ] **Q-RE-011** 报告格式是否符合准则或指南要求？是否包含对应准则必须披露的内容？章节内容和名称是否符合报告准则？
      - 判定要点：如不得把「评估程序实施过程和情况」写成「评估过程」
- [ ] **Q-RE-012** 报告签字人与评估明细表列示的签字人是否相符？
- [ ] **Q-RE-013** 评估报告中是否有注册资产评估师声明或承诺函？
- [ ] **Q-RE-014** 涉及国有资产评估的项目，报告附件是否有经济行为依据？
      - 判定要点：无法获得的须在送审时单独说明并获三级审核人员同意
- [ ] **Q-RE-015** 经济行为依据中的评估目的等表述与业务约定书中的评估目的是否存在矛盾？
- [ ] **Q-RE-016** 是否有评估对象的资产权属证明文件？
      - 判定要点：单项资产需权属证书（含他项权证）；股权项目需股权证明文件及不动产权属证书
- [ ] **Q-RE-017** 企业价值评估报告是否附评估基准日审计报告或财务报表？
- [ ] **Q-RE-018** 股权价值评估是否附长期投资单位的营业执照复印件或股权证明文件？
- [ ] **Q-RE-019** 是否附资产评估业务约定书？
- [ ] **Q-RE-020** 附件营业执照上的单位名称与报告中描述的单位名称是否完全一致？
      - 判定要点：重点核查近期更名的单位
- [ ] **Q-RE-021** 所附个人资质证书与报告、明细表列示的签字人是否一致？
- [ ] **Q-RE-022** 涉及国有资产或企业价值评估项目的评估说明中是否有资产清查章节？
- [ ] **Q-RE-023** 评估说明中是否有主要资产的评估案例？
      - 判定要点：主要资产一般包括存货、房屋及构筑物、管道沟槽、机器设备、车辆、土地、长期待摊费用（装潢）、生物性资产、无形资产等
- [ ] **Q-RE-024** 评估案例的序号、评估值与评估明细表中列示的序号、评估值是否一致？
- [ ] **Q-RE-025** 采用资产基础法评估股权价值时，各科目的评估说明是否齐全？
      - 判定要点：国有资产和上市公司项目应对各科目评估值的得出给出书面说明
